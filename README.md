1. Install git respective OS(latest)
2. Create github account
3. Create repository (provde any name)
     1. click on profile
	 2.click repositories tab from menu
     3. click on New button(green new button right sde top)
	 4. provide repository name(ex: technosanta)
	 5. click add ReadME file radio button (ON)
	 6.check config needed according to your project requirememts
	 7.Click on create repository button on below
4. Go to your recent created repositories
5. By default selected main brnch left side top showing branch
6. clone project by click Code button on right top side (green button) -> HTTPS selected -> copy URL
7. Go to folder in your system -> Create Folder for project(ex: Python_selenium_pytest)
8. right click mouse and click on "open Git Bash Here"
9. provde command - git clone <copied URL above> (ex: https://github.com/technosanta/Python-selenium10.git)
10. Clone Done wit 100% message successfully
